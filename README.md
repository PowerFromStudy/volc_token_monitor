# volc-token-monitor

火山引擎（Volcengine）专用 Token 监控系统。

## 项目简介

对火山引擎 API 凭证（Access Key / Secret Key、临时 Token 等）进行统一监控与告警，计划能力包括：

- Token 有效期监控与到期提醒
- 使用量 / 配额监控与阈值告警
- 异常调用检测与通知
- 多账号、多项目凭证统一管理（后续扩展）

> ⚠️ **安全提示**：本仓库为**公开仓库**，严禁提交任何真实 Token、AK/SK、`.env` 等敏感信息。敏感配置仅通过本地环境变量或不入库的私有配置文件注入。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `docs/` | 项目文档（设计、接口、部署说明等） |
| `src/` | 源代码 |
| `scripts/` | 运维、部署、调试脚本 |
| `config/` | 配置文件（仅提交示例配置，真实配置不入库） |
